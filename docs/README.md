# docs/

Background material and external references.

These are **not** the source of truth. Anything here that contradicts
`plans/` is out of date; follow `plans/`.

The completed preparation-phase research (design reasoning, measured
verification records, test findings) is archived under `prepare/` and is
kept read-only.

Reproducible implementation probes may be documented under `docs/probes/`.
Scripts belong in `tools/` or regression tests in `test/`; accepted project
rules and decisions must also be stated in `plans/`.

`current-user-flow.md` is a source-based walkthrough of the implemented
configuration, checkout, locking, local editing, submit, conflict review, and
cleanup behavior. It explains current code and does not replace `plans/`.
